# 石油中文期刊论文助手

面向石油与天然气工程领域的 Codex Skill，帮助撰写和审查中文期刊论文，重点支持**钻井工程**与**油气田开发**方向。

## 功能

- 辅助梳理选题、研究问题、论文提纲和章节内容。
- 检查专业论证、方法描述、参数单位、图表及结论适用范围。
- 为岩屑输运与井眼清洁研究提供机理模型、实验相关式、瞬态模拟及现场案例的结构和论证参考。
- 追踪关键论点与数据、模型输出、图表或文献之间的对应关系，区分实测、推断和待核验信息。
- 协助核对文献题录，并检查模型标定、独立验证、现场案例和工程效果的证据边界。
- 根据目标期刊的现行投稿要求检查摘要、格式、引文和投稿材料。

## 使用

在 Codex 中调用：

```text
$petroleum-paper-assistant
```

开始任务时提供研究主题、已有数据或草稿，以及目标期刊（如已确定）。可以在 `assets/paper-config.yaml` 的副本中记录每篇论文的研究资料和期刊要求。

本 Skill 提供写作与审查辅助。研究数据、技术结论和引用仍需作者核实；期刊格式以目标期刊最新官方指南为准。
