# 期刊格式示例：石油勘探与开发

本文件仅作为一个可选示例，不代表所有中文石油期刊格式。目标刊为其他期刊时不得套用。本文档根据官网《投稿须知》页面核对；访问日期：2026-10-21。投稿前重新查看官网、下载最新模板并确认更新。

来源：[《石油勘探与开发》投稿须知](https://www.cpedm.com/CN/column/column5.shtml)。

该页面列出的要点包括：题名一般不超过20个汉字；论文需有中、英文摘要和关键词，中文摘要约300字并体现目的、方法、结果、结论；正文要求论点明确、数据可靠，表格采用三线表，图件清晰、图例齐全，量和单位符合国家法定标准，公式连续编号并解释符号；参考文献采用顺序编码制并遵循页面所述 GB/T 7714—2015 要求，中文参考文献附英文译文，文献数量不少于10篇；稿件页数控制在12页以内。以上均为该页面呈现的该刊要求。

应用规则：

- 只有用户指定该刊，或明确要求按该刊格式审查时，才使用此配置。
- 逐项对照官网最新指南和格式模板；页面可能更新，用户也可能适用特刊或栏目规则。
- 页面上未列明或模板与指南表达不一致的项目，标记为“需编辑部/作者确认”，不自行补写规则。
- 不据此对其他期刊推断题名长度、摘要字数、参考文献数量、格式或页数要求。
