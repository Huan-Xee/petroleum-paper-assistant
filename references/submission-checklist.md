# 中文期刊论文投稿前检查清单

先读取目标期刊最新投稿指南和官方模板。表中的通用检查不能覆盖期刊的明确规则；冲突时标出具体来源和版本，并以作者确认的目标刊规则为准。

## 研究内容

- [ ] 题名准确反映对象、问题或方法，没有超出证据的承诺。
- [ ] 摘要概括研究目的、方法、主要定量结果和结论；摘要中的数字与正文一致。
- [ ] 关键词能检索到研究对象、方法和核心技术，不只是宽泛领域词。
- [ ] 引言指出具体工程/科学问题、相关研究进展、本文要补足的缺口和研究目标。
- [ ] 方法交代关键数据、对象、参数、假设和分析步骤；结果与讨论区分观测结果和解释。
- [ ] 结论逐条对应研究问题和结果，量化结论可回溯到图表/数据，并交代适用边界。
- [ ] 局限性、异常值、对照可比性及不确定性得到适当说明。

## 数据、图表与引文

- [ ] 重要结论可追溯到原始数据、计算过程、图表或经过核验的文献。
- [ ] 图表在正文有引用；编号、标题、坐标、单位、图例和数据来源齐全且一致。
- [ ] 公式编号连续（如目标刊要求），符号定义、上下标和量纲无明显冲突。
- [ ] 数量、单位、有效数字、统计口径和图文中的值一致；疑似不一致已向作者确认。
- [ ] 引文与参考文献一一对应；关键文献的题录和论点匹配已核验。
- [ ] 图件版权、转载许可、作者署名、基金信息和保密要求按作者/期刊要求核对。

## 期刊与文件格式

- [ ] 作者、单位、基金、通讯作者、作者简介和利益/伦理声明符合该刊要求（适用时）。
- [ ] 中英文题名、摘要、关键词、机构英文名等按该刊要求提供。
- [ ] 标题层级、字体、字号、段距、页边距、表格、图件分辨率/格式和附件符合模板。
- [ ] 文献著录体例、标点、顺序、英文大小写等符合该刊模板。
- [ ] 稿件长度、文件命名、匿名要求、投稿系统附件和声明材料已核对。

## 报告结果

按“通过 / 需作者确认 / 需修改 / 当前无法核验”汇总。格式问题注明对应期刊指南条目或模板页；无法定位规则时标记待确认，不自称已符合该刊要求。文本检查不能替代 Word 页面渲染和期刊投稿系统的最终校验。
